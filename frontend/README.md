# DataFence 本地控制台

React / TypeScript / Vite 界面，所有演练、事件、风险与评测指标均来自 `/api`。

```powershell
npm ci
npm run dev
```

开发地址为 `http://127.0.0.1:5173`，API 代理至 `http://127.0.0.1:8765`。生产构建使用 `npm run build`，生成的 `dist/` 由 FastAPI 同源服务；首次构建后需启动或重启后端，使静态资源目录生效。

前端包括七个核心页面，以及数据资产、实际数据流、六个安全能力模块、策略只读视图、哈希链校验与系统状态。全局搜索范围为员工与首页最近事件；风险事件列表覆盖最近 100 条并支持分级筛选及分页。

工作台先通过 `/api/auth/status` 与 `/api/session` 验证身份，再加载业务数据。首次本机初始化仅在服务端明确允许时开放，没有默认账号密码；未授权的远程初始化提示部署管理员使用服务器管理脚本。管理员、分析员与只读观察员的权限由服务端执行，前端同步禁用只读账号的演练、评测和导入操作。系统管理提供当前账号退出及管理员账号创建、角色调整、启停和密码重置；收到业务 401 后卸载工作台，清空旧页面状态。

数据资产页分开展示合成沙盒资产与公开业务数据的来源、许可、摘要及质量聚合，不展示公开数据原始行，不将业务目标列视作攻击标签。合成安全日志可使用 JSONL / CSV 导入，每批最多 1 MiB、2,000 行，由服务器整批校验后进行观察分析。导入不执行响应、不扣额度、不调用云模型；分页结果中的动作是建议，不是已发生的阻断。

受控合成数据访问入口使用 `/api/access`，由服务端先核验平台角色、业务工单、规则与独立的工单生命周期额度，再返回实际合成客户 JSON / CSV。普通权限或 CSRF 403 仍报错；只有匹配本次请求编号、明确拒绝且不含客户行的网关 403 回执作为拒绝依据展示。网络失败可重试同一请求编号，新操作明确生成新编号。CSV 仅在服务端获准并返回内容后提供下载，公开业务行不进入网关。

语言模型界面兼容商汤 SenseNova 云 API 与 Ollama 本地服务。系统管理和 AI 安全智能体页分别展示配置、最近调用结果、模型名称及 UTC 计量日预算；预算是后端 SQLite 中的本地控制额度，不代表供应商账户余额。工单规则计算意图匹配分；商汤执行前语义核验结果由本地策略决定涉敏 AI 请求的风险与处置；普通事后解释和建议仅供参考，不授权动作。事件级调用、原文证据、token 计量与实际响应分别展示。云预训练大模型与项目本地训练的行为检测模型始终分开说明。

实时监控与实验室显示后台当前阶段及等待时长，区分执行前语义核验与事后附加解释。所选事件的风险与动作只读取已保存结果。事件详情展示额度决策时的账本快照；容量按获准 QUERY / API 请求的记录数累计，预留也占用额度，不等同于去重客户数或实际返回量。

安全约束：不嵌入 API 密钥、不存储认证令牌或密码到浏览器存储、不渲染原始 HTML；请求和分析文本通过 React 文本节点展示。登录会话由服务器 HttpOnly Cookie 维护，写请求发送只保留在内存中的 CSRF 令牌。浏览器端不执行检测、冻结或数据库修改。

当前的人工复核、解除冻结、策略编辑、审批流程未实现，页面明确标注。画像仅比较后端实际提供的每日记录数与查询数基线，不生成虚构的其他正常维度。评测不把未执行步骤补成已发生链路，也不将固定合成模板指标当作真实银行准确率。

验证：`npm run build`；依赖审计使用 `npm audit --registry=https://registry.npmjs.org`（本机默认镜像不支持审计 API）。锁文件应随依赖更新一并提交。
